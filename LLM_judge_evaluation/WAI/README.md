## WAI

WAI (Working Alliance Inventory) evaluates the therapeutic alliance between the client and the counselor across 12 different items.

---

### `prompts/`
Contains the prompts used to evaluate each of the 12 WAI items.

---

### `wai-gpt4o.py`
Scores each WAI item for every generated session using GPT-4o.

| Argument | Description |
|---|---|
| `-i` | Path to the directory containing the sessions to be rated |
| `-o` | Path to the output directory where WAI scores will be stored |
| `-m_iter` | Number of times GPT-4o is run per item per session (final score is the average) |
| `-oai_key` | OpenAI API key |
```bash
python wai-gpt4o.py -i input_dir -o output_dir -m_iter num -oai_key openai_api_key
```

---

### `rating.ipynb`
Aggregates WAI scores by calculating the average score for each item across all sessions generated by a particular method. Update the path to the WAI scores output directory before running.
