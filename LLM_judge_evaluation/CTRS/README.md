## CTRS

CTRS (Cognitive Therapy Rating Scale) evaluates counseling sessions across six different categories of counseling competence.

---

### `prompts/`
Contains the prompts used to evaluate each of the six CTRS categories.

---

### `ctrs-gpt4o.py`
Scores each CTRS criterion for every generated session using GPT-4o.

| Argument | Description |
|---|---|
| `-i` | Path to the directory containing the sessions to be rated |
| `-o` | Path to the output directory where CTRS scores will be stored |
| `-m_iter` | Number of times GPT-4o is run per criterion per session (final score is the average) |
| `-oai_key` | OpenAI API key |
```bash
python ctrs-gpt4o.py -i input_dir -o output_dir -m_iter num -oai_key openai_api_key
```

---

### `rating.ipynb`
Aggregates CTRS scores by calculating the average score for each criterion across all sessions generated by a particular method. Update the path to the CTRS scores output directory before running.
